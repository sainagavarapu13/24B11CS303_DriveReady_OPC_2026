# Day 1 – Sweet Crumbs Home Bakery Chatbot

## Learning and Implementation

Studied the fundamentals of Artificial Intelligence and Large Language Models (LLMs), understanding how AI systems process user inputs and generate human-like responses.

Explored the following concepts:

1. **Introduction to AI:** Understanding why AI is widely used in modern applications and its real-world impact.
2. **What an LLM Does:** Learned how Large Language Models understand text and generate responses based on input.
3. **Tokens:** Understood how text is divided into smaller units called tokens before processing.
4. **Temperature:** Learned how temperature controls the randomness and creativity of AI-generated responses.
5. **AI Memory:** Understood why LLMs do not automatically remember previous conversations.
6. **Context Window:** Learned how much information a model can process within a single interaction.
7. **Hallucinations:** Explored how AI can sometimes generate incorrect or misleading information.
8. **Role of an AI Engineer:** Understood the responsibilities involved in building and integrating AI-powered applications.
9. **First API Call:** Connected to an LLM using Python and learned how to send prompts and receive AI-generated responses.

## Project Implementation

Created the initial version of the Sweet Crumbs Home Bakery chatbot using Python and an LLM API.

The chatbot is designed to act as a virtual bakery assistant that can:
- Respond to customer greetings and enquiries.
- Provide information about bakery products.
- Answer questions about eggless cake availability.
- Assist customers with basic order-related queries.
- Generate natural-language responses based on customer inputs.

## Key Learning Outcomes

Gained practical experience with LLM fundamentals, prompt-based interaction, API integration, AI response generation, and the initial development of a conversational AI application.

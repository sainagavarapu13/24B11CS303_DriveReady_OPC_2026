Explored the fundamentals of LLM conversations and Python concepts through the development of a customer support chatbot using the OpenAI Python SDK and Groq API.

Implemented structured messages with system, user, and assistant roles. Designed system prompts to define chatbot behaviour and business rules, and explored few-shot prompting and JSON-based responses.

Implemented conversation memory using Python lists and dictionaries to maintain chat history and remember customer details.

Created reusable functions with type hints, implemented decorators for logging function calls, and used exception handling with `try/except` to manage API rate limits and connection errors.

**Key Learning Areas:** Messages and Roles, System Prompts, Few-Shot Examples, JSON Responses, Conversation Memory, Python Dictionaries, Functions and Type Hints, Decorators, and Exception Handling.
